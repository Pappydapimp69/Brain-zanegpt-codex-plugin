## E1 — empathy map density hides evidence gap and simulation masks sparseness
- Date: 2026-10-09
- Project: local/sandbox-empathy-map-density-hides-evidence-gap
- Tags: [empathy][design][research][simulation][method]
- What: A deterministic hash-seeded sandbox MODEL of an empathy map (4 quadrants, 12 candidate statements each, a 16-statement true core measured from a 200-user population) filled three ways: from the designer's imagination, from N representative interviews with a 2-voice corroboration bar, and from interviews plus a vivid simulation exercise whose items skip corroboration.
- Why built: The EMPATHY design-practice kernel says a sparse empathy map signals missing research, and that simulation exercises can widen the gap they claim to close. Both are about human behaviour, so the sandbox can only test the logical structure, namely whether the "sparse means research more" alarm survives each fill route and where it stops working.
- Design: Truth is computed from the simulated population, not assumed. Maps are scored on density, true items, false assertions, precision, and a per-quadrant sparse alarm (fewer than 2 items). The simulation arm reuses the identical interview evidence as the no-exercise arm (a matched counterfactual, one variable changed). Scenarios: imagined vs interviews over N, exercise at N=3 and N=24, designer equals user, convenience sample, exercise fidelity rho=1.0, vividness sweep, plus positive and empty controls.
- Got right: Printing density next to precision exposed the blind spot directly: an imagined map (14 items, 0 alarms, precision 0.29) and a 12-interview map (16 items, 0 alarms, precision 1.00) are indistinguishable by density or alarm. Matching the evidence between arms made the exercise effect attributable: at N=3 it silenced 4 of 4 sparse alarms (density 3 to 13) while false assertions went 0 to 9; at N=24 it changed nothing.
- Where/why it failed: One pre-registered breaker missed: with designer equal to user, imagined precision was 0.69, not the predicted 0.90 or more, because my imagination model fills 30 percent of slots at random; with that filler removed it is 1.00 (post-hoc diagnostic). A second guess, that vividness 1.0 would be inert, was wrong: one real mention plus 1.0 vividness clears the corroboration bar, so masking is graded (false items added 0, 4, 9, 9, 9 at vividness 0, 1, 2, 2.5, 4). Harm also fades slowly with N (added false items 9, 9, 5, 4, 4, 2, 0 at N=0, 3, 6, 9, 12, 18, 24).
- Fix: State the claim narrowly: a sparse alarm is a valid missing-data signal only for maps whose content must be corroborated; any route that adds uncorroborated content (imagination, a convenience sample of colleagues, a simulation exercise) can fill the quadrants and silence the alarm while precision falls to 0.25 to 0.31. Judge a map by its provenance and sample, with density as a secondary check, and give simulation items the same corroboration bar as everything else.
- Why this fix: The alarm reads density, and density is something unverified content can supply, so the check has to move upstream to where each item came from. The two boundaries found (designer overlap, exercise fidelity) show the risk is conditional, so the rule does not forbid imagination or exercises, it forbids letting them count as evidence.
- Rule of thumb: In this model a sparse-quadrant alarm only detects missing evidence when items need corroboration: an imagined map (precision 0.29), a colleague-only interview map (0.25) and a thin-evidence map padded by a vivid exercise (0.31 at N=3) all show a full map and zero alarms, so audit where each item came from and hold exercise items to the same two-source bar; it stops mattering when the designer actually matches the users or the exercise is high fidelity (false items 0 at rho=1.0). This is a logic model, not evidence about real designers.
