## E1 — chekhov ledger checker unfired spotlight unintroduced resolver dead end and motif false positive
- Date: 2026-10-10
- Project: local/2026-10-10__chekhov-ledger-checker-unfired-spotlight-unintroduced-resolver-dead-end-and-motif-false-positive
- Tags: [storytelling][economy][tooling][sandbox][testing]
- What: A beat-ledger checker applies the Chekhov's-gun promise to three hand-built six-beat stories with three rules: every spotlighted detail needs a later action, reveal or consequence use (R1), every use needs an earlier introduction (R2), and every detail's chain must reach the final beat (R3). Five mutation operators test whether each rule catches its intended defect.
- Why built: The kernel states the promise but no memory entry had built against it; the songwriting kernels extended it with typed uses and reachability, and I wanted to see which defects a promise-only check misses in plain story beats and where the typed checker itself is wrong.
- Design: Python ledger of beats with plants, typed uses and unspotlighted background mentions. Mutations: drop a use, remove an introduction, turn a use into an echo, clear a mid-story beat's plants so a chain dead-ends, and delete a background mention (the control that must flag nothing). A promise-only checker (any later use counts) is run beside it.
- Got right: Unmutated stories raised 0 flags. Each rule caught its intended mutation 3 of 3, the background deletion flagged nothing 3 of 3, and the promise-only check missed all 3 echo-only and all 3 dead-end mutations, so typed uses and reachability are what catch them.
- Where/why it failed: A legitimate recurring motif, planted and only echoed on purpose, is flagged by R1 (1 of 1), so the checker has a false positive on deliberate motifs until an explicit motif exemption is added; with the exemption it raised 0 flags. The stories are hand-built and the mutations hit rules written for them, so detection rates are an upper bound, not a measured accuracy.
- Fix: Add an explicit motif marker that exempts echo-only details from R1 while still requiring the detail to be planted early, and keep R2 and R3 unexempted.
- Why this fix: The motif is the one case where an echo is the intended payoff; marking it by the author keeps the rule strict everywhere else instead of loosening it to accept echoes.
- Rule of thumb: Check a spotlighted detail with typed uses and a chain to the ending, not by whether it is mentioned again; expect false positives on deliberate motifs and mark them explicitly rather than relaxing the rule.
- Provenance (verified/assumed): Verified first-hand by running the sandbox once (RESULT: PASS). Scope is limited to my three hand-written stories and five mutations; the Chekhov letter history is out of scope here.
