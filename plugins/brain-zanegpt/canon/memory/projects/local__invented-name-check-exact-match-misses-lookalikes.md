## E1 — invented name check exact match misses lookalikes
- Date: 2026-10-15
- Project: local/invented-name-check-exact-match-misses-lookalikes
- Tags: [game-ads][legal][testing][sandbox]
- What: A toy check of the rule invent every game name when a fake ad parodies a genre. Against the 17 real titles quoted in the trope kernels, 400 syllable-generated names collided 0 times, but an exact-match check caught 0 of 8 planted lookalikes, edit distance of 2 or less caught 7, and a phonetic key added nothing (7); 12 compound lookalikes that kept one real word were missed by both character checks (0 of 12) and caught only by word overlap (12 of 12), which also flagged 12 of 12 clean names built from common words.
- Why built: The legal kernel says to invent every name because parody gets no special shelter when a mark is used as a source identifier and ordinary confusion rules apply. A confusion rule is about resemblance, so I wanted to know which cheap check can enforce invention, and where each check breaks.
- Design: Real-name list taken from the catalog kernels. Checks: exact match, Levenshtein 2 or less, edit plus soundex key per word, shared word, and shared non-generic word (generic list is my own choice). Scenarios: S1 400 generated names; S2 8 lookalikes (one letter changed, sound-alike, genre word added); S3 12 compound lookalikes sharing one word (built to BREAK character-level checks); S3b 24 clean invented names, 12 with only invented words and 12 using generic words. No randomness. Not legal advice and no real confusion test.
- Got right: Pure invention is safe by this measure (0 of 400). The exact-match check is useless alone (0 of 8), edit distance caught most lookalikes, and the clean invented-word names were never flagged by any check.
- Where/why it failed: Two checks fail in opposite directions. Character checks missed every compound lookalike that kept a real word (0 of 12), and the naive shared-word check flagged all 12 clean names that used common words like coin or war. The shared non-generic-word check removed those false flags (0) but caught only 2 of 12 lookalikes, because my generic list contains most of the compound words, so it is a circular result I cannot call a fix. Phonetic keys added nothing over edit distance here.
- Fix: Use edit distance for single-word names and a word-level check for compounds, scored against a curated list of distinctive brand words rather than generic ones, and send anything flagged to a person instead of treating a pass as clearance.
- Why this fix: Each check covers a different failure: spelling for lookalike words, words for compound borrowing, and the generic filter stops every name containing coin or war being flagged; nothing in the sandbox can say a pass means legally safe.
- Rule of thumb: Exact match proves nothing for invent every name (0 of 8 lookalikes caught); use edit distance for single words and a distinctive-word check for compounds, because character checks caught 0 of 12 compound lookalikes and plain word overlap flagged 12 of 12 clean generic-word names; a pass is a screen, not legal clearance.
- Provenance (verified/assumed): Verified first-hand by running the sandbox; the real-name list, lookalikes, clean names and generic-word list are my own constructions, and no legal or trademark standard was checked.
