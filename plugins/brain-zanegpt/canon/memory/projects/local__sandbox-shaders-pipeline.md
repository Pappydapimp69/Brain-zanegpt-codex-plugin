## E1 — srgb blend normal pipeline
- Date: 2026-10-10
- Project: local/sandbox-shaders-pipeline
- Tags: [rendering][algorithm][testing]
- What: Sandbox of two shader-math kernels together: sRGB-space lerp versus linear-light lerp, and normal transform by model matrix versus inverse-transpose under non-uniform scale.
- Why built: To check both kernels hold and to find where each stops mattering, since each is easy to apply everywhere out of habit.
- Design: Pure-python scalar sandbox. S1 50% white/black blend measured as linear luminance; S2 error versus colour distance; S3 plane normal under scale (1,1,4) checked for perpendicularity to a scaled tangent; S4 uniform scale; S5 Lambert term for both normals.
- Got right: S1 reproduced 0.214 versus 0.500 exactly. The sRGB-lerp error scales with colour distance: 0 at distance 0, 0.00012 at 0.02, 0.0029 at 0.1, 0.073 at 0.5, 0.286 at 1.0. Inverse-transpose normal had dot 0.0 with the tangent; the model-matrix normal had -3.64.
- Where/why it failed: S4 uniform scale: both normal methods agreed to 0.0, so the non-uniform-scale caveat is real. S5 Lambert intensity was identical (0.8575) for both because the chosen light is symmetric to the plane; that scenario did not discriminate, so a shading-level check needs an asymmetric light.
- Fix: Convert to linear before blending whenever colours are far apart (blends, filtering, mips); skip worry for near-identical colours. Use the inverse-transpose only when scale is non-uniform; assert perpendicularity against a transformed tangent rather than comparing shaded output with a symmetric light.
- Why this fix: The measured error curve shows where the cost of correctness is worth paying, and the tangent-perpendicularity test is a direct invariant that a symmetric-light shading comparison missed.
- Rule of thumb: The sRGB-lerp darkening error grows with colour distance (negligible under about 0.1 apart), and the model-matrix normal is only wrong under non-uniform scale; test normals by perpendicularity to a transformed tangent, not by lit output with a symmetric light.
- Provenance (verified/assumed): Verified first-hand by running the sandbox; all numbers above are from the run.
- Composed: ideas:SHADERS/color-blending/convert-to-linear-before-blending-physical-light, ideas:SHADERS/normals/transform-normals-by-the-inverse-transpose-not-the-model-matrix, sandbox-shaders-gamma/E1
