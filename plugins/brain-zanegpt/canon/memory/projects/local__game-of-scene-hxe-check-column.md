## E1 — game of scene hxe check column
- Date: 2026-10-15
- Project: local/game-of-scene-hxe-check-column
- Tags: [comedy][narrative][testing][sandbox]
- What: A toy checker for the game-of-the-scene beat sheet's H/E/X check column (heighten, explore, new game). Over 6 hand-labelled four-beat sheets, a naive rule that marks X for any newly named unusual thing matched the truth labels on 4 of 6; adding a derived-from-game link, flat and jump labels and a separate stock-premise check matched 6 of 6.
- Why built: The kernel says any X beat must be cut. I wanted to know whether a "new unusual thing" test can actually mechanise that column, and where it stops being the same as "new game", using the sibling hack-premise-check kernel and the step-coherence finding from sandbox-comedy-escalation as extra probes.
- Design: Each beat is (unusual things present, intensity, explains-why flag, derived-from-game flag). Naive rule: new thing means X, explains means E, intensity above the running max means H. Fixed rule: a new thing is X only if it is not derived from the game; a rise of more than 3 intensity units at once is J (jump); no rise is F; the premise is checked against a stock list. Scenarios: clean, planted second game, flat repeats, derived consequences (built to break the naive rule), stock premise, one huge jump. No randomness.
- Got right: Clean sheet and planted second game (alien landing at beat 3) were labelled exactly by the naive rule, so X detection of a genuinely foreign element works. A stock premise (office desk evolution) passed the H/E/X column untouched, so the hack check is a separate gate.
- Where/why it failed: The naive rule flagged 2 legitimate beats (loan forms in the bark, vault of bones) as X in scenario 4, because a derived consequence of the game names a new noun. The plain column also has no label for flat repetition or a too-big jump (scenarios 3 and 6 show unlabelled beats). My scoring relabelled the naive "-" as F post hoc, which flatters the naive rule on scenario 3.
- Fix: Mark each new thing with whether it follows from the game's own premise, treat X as new thing without that link, and add F and J columns plus the stock-form check before the sheet is accepted.
- Why this fix: It moves the cut decision from the noun (which varies) to the dependency (does this follow if the first unusual thing is true), which is exactly the kernel's heighten question, and it kept 6 of 6 scenarios exact while the naive rule kept 4 of 6.
- Rule of thumb: In a game-of-the-scene sheet, cut a beat as X only when its new element does not follow from the first unusual thing; add flat and jump columns and run the stock-premise check separately, because the H/E/X column alone passed flat, oversized and hackneyed sheets (tested on 6 toy sheets, hand-labelled by me).
