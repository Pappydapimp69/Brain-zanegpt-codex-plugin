## E1 — hyphenation shortens the text a spelling rhyme judge reads
- Date: 2026-10-19
- Project: local/hyphenation-shortens-the-text-a-spelling-rhyme-judge-reads
- Tags: [songwriting][rhyme][simulation][method]
- What: An exhaustive run over all 20736 four-line stanzas from 12 end words, scoring a spelling rhyme judge (last 3 letters of the last token) against a hand-keyed phonetic truth, once on the plain words and once on the hyphenated forms such as glad-ly and to-night.
- Why built: The hyphenation kernel tells a writer to split words to slow a sung line, and the spelling-judge lesson says lettering cannot rescue a judge that reads spelling. Together they predict that the text change feeds a spelling judge different letters.
- Design: Each word has a hyphenated spelling and a perfect-rhyme key. The judge reads the last 3 letters of the final token after splitting on hyphens. Score is whether the perfect-rhyme partition of the four lines equals the phonetic partition, which is the grouping the uppercase pass of two-pass lettering starts from. The lexicon deliberately holds five words ending in ly, so it leans toward the failure it tests.
- Got right: Hyphenation measurably moves the spelling judge: its verdict changed in 7346 stanzas (35.4 percent), and the failure is traceable to 7 word pairs such as freely and gladly whose last token shrinks to ly.
- Where/why it failed: The spelling judge was already wrong in 5444 stanzas (26.3 percent) on plain text, and hyphenation made it worse, 12118 (58.4 percent), repairing 0 stanzas and breaking 6674. Nothing about two-pass lettering helps, since the damage is upstream of it.
- Fix: Judge rhyme on the unhyphenated word or on its stressed-syllable key, and apply hyphens only to the text sent to the singer; if a spelling judge must be used, strip hyphens first.
- Why this fix: The hyphen shortens the final token below the 3-letter window, so unrelated endings collapse to the same suffix; stripping hyphens restores the window.
- Rule of thumb: A spelling rhyme judge went from wrong in 26.3 percent of 20736 stanzas to 58.4 percent once end words were hyphenated, repairing none, so strip hyphens before judging rhyme and hyphenate only the sung text.
- Provenance (verified/assumed): Verified first-hand by running the saved sandbox, PASS on the first run with deterministic output; the 12-word lexicon, its phonetic keys and the 3-letter window are my own hand-written choices, and no real rhyme tool or vocal model was used.

- ZaneGPT verdict: weak — the 0 repaired and 6674 broken counts are real for this lexicon, but the design is circular: it splits on hyphens, then blames the hyphen. The -ly-heavy word list guarantees the result, so the number cannot generalize, and "PASS" only confirms the prediction the lexicon was built to meet.
- Hidden assumption: A "wrong" judge verdict means the spelling judge fails to match the hand-keyed phonetic truth, and a hyphenated end word should be judged on its post-hyphen fragment, as if the judge must read that fragment. Nothing tests the other reading, where the judge reads the full unsplit word. The rule also assumes that a lexicon built to over-represent -ly (5 of 12 words) and a hand-keyed "truth" are representative of real end words, and that the 26.3% and 58.4% figures carry beyond this lexicon.
- Would prove it wrong: Run the same 20736 stanzas with the judge reading the last 3 letters of the full hyphen-stripped word. If its error rate on plain words matches the hyphenated rate, or hyphenation no longer changes the partition, the damage came from splitting on hyphens and not from hyphenation itself. The rule's "strip hyphens before judging" fix would still hold, but the claim that hyphenation breaks rhyme judging would not. A reweighted lexicon with 0 or 1 -ly words that still shows a large gap would also test the generality, and a gap that vanishes would refute it.
- Break scenario: Lexicon-shift test: drop four of the five -ly words and add ordinary words whose last syllable is a short fragment after a hyphen, such as to-night/de-light (-ght) or re-ply/hi-fly (-ply, -fly). The 3-letter tail of the last token then often equals the phonetic rhyme (-ght, -ply), so hyphenation should not break much and could repair some stanzas where the plain tail is misleading. The "repaired 0" result is a lexicon artifact if a single repaired stanza appears. Note that the BREAK scenario, which counts repairs, found 0 only on this word list.
