## E1 — double dissociation needs a state trace test one latent with crossing curves fakes it
- Date: 2026-10-14
- Project: local/sandbox-double-dissociation-state-trace
- Tags: [empathy][method][simulation]
- What: A deterministic sandbox shows that a lesion double dissociation (one patient intact on affective but impaired on cognitive empathy, another the reverse) can be produced by ONE latent capacity when the two task curves cross: 20 patient pairs at margin 0.15 with crossing curves versus 0 with non-crossing ones. A state-trace check (are the two scores a monotone function of each other) separated the one-latent models (0 violations) from a two-latent model (2).
- Why built: The affective-versus-cognitive empathy kernel rests on a double dissociation, and the distress-versus-compassion kernel claims separate networks, so I wanted to know what a dissociation pattern can and cannot rule out about the number of underlying systems.
- Design: Python, stdlib, no RNG. Patients on a 21-level grid of one latent r; non-crossing curves aff=r, cog=r squared; crossing curves aff=r, cog=clip(3r-0.6). Counted ordered patient pairs where one scores 0.15 higher on aff and the other 0.15 higher on cog. A direction-agnostic monotone state-trace violation count was run on one-latent traces, a five-point two-latent set, a distress/compassion dose line (compassion = 1 - distress) and the same line plus a compassion-training arm (compassion up at low distress).
- Got right: Iteration 2 reproduced the prediction in all seven measures: double dissociations 0 versus 20, state-trace violations 0, 0, 2, 0 and 2 for non-crossing, crossing, two-latent, dose line and trained arm.
- Where/why it failed: Iteration 1 failed its own prediction: with margin 0.2 and cog=clip(2r-0.3) the floor at zero capped the gap at 0.1, so crossing curves produced zero double dissociations. I changed the margin and curve, then re-ran, so the 20 is a tuned result and not an unchanged prediction; floor effects limit how large a one-latent double dissociation can be. The dose line also showed that a clean negative dose-response (0 violations) cannot show separate distress and compassion networks.
- Fix: Treat a double dissociation as evidence for two systems only after checking that the two scores are not a monotone function of each other across all patients and conditions (state-trace), and test separate-network claims with a manipulation that moves one measure while the other stays flat.
- Why this fix: In the run the one-latent crossing model passed every dissociation count yet had a monotone trace, while the two-latent set and the trained arm each broke monotonicity, so the trace separates what the dissociation count cannot.
- Rule of thumb: In this model, a double dissociation alone does not prove two systems, because one latent with crossing task curves produced 20 qualifying pairs; require a non-monotone state-trace or a manipulation that moves one measure with the other flat, and be aware that floor effects shrink the dissociation a single latent can fake.
- Provenance (verified/assumed): Verified first-hand by running the saved sandbox; every number is its printed output. The curves, grid and margin are my own synthetic choices, not patient data, so nothing here tests real empathy research; the lesion literature is the kernel's claim and was not checked.
