## E1 — hyphenating end words breaks two pass letters only under a last segment judge
- Date: 2026-10-19
- Project: local/hyphenating-end-words-breaks-two-pass-letters-only-under-a-last-segment-judge
- Tags: [songwriting][rhyme][simulation][method]
- What: An exhaustive run over all 6561 four-line stanzas drawn from 9 hand-keyed end words, comparing two-pass rhyme lettering when the rhyme judge keys the whole word (stressed syllable to the end) against a judge that only sees the last hyphen segment, as happens once an end word such as mo-tion is split to slow a vocal line.
- Why built: The hyphenation kernel says to hyphenate multisyllabic words to force syllable timing, and the two-pass lettering lessons assume a sound rhyme judge. I wanted to know whether the first technique can corrupt the second.
- Design: Each word carries its hyphen segments, a (vowel, coda) pair per segment and a stressed segment index. Two-pass lettering gives uppercase to perfect-rhyme groups, then lowercase to assonance among leftover lines. The truth partition is the perfect-rhyme groups under the whole-word key; the segment judge keys only the final segment, where unstressed segments collapse to a schwa.
- Got right: The whole-word judge matched truth in all 6561 stanzas, so splitting the written word cannot hurt lettering as long as the judge keys the unhyphenated word.
- Where/why it failed: My check that hyphenation leaves the whole-word letters unchanged is true by construction, since the same function sees the same words, so it proves nothing by itself. The real finding is the other judge: keying only the last segment merged motion, ocean and nation (three false pairs) and gave a wrong perfect-rhyme partition in 1794 of 6561 stanzas (27.3 percent).
- Fix: Strip hyphens and key the whole word, or carry the stressed-syllable key with the word, before lettering; apply hyphenation only to the text sent to the singer.
- Why this fix: The wrong merges come from unstressed segments like tion and ful looking identical, which only a stressed-syllable key can tell apart, and the key must be computed before the word is split.
- Rule of thumb: Hyphenating end words is harmless to rhyme lettering when the judge keys the whole word (0 of 6561 stanzas wrong) but a last-segment judge mislettered 27.3 percent of stanzas, so key the unhyphenated word and hyphenate only the output text.
- Provenance (verified/assumed): Verified first-hand by running the saved sandbox, PASS on the first run with deterministic output; the 9-word lexicon and its phonetic keys are hand-written by me, and whether Suno rushes or slows a hyphenated line is taken from the kernel and was not tested.

- ZaneGPT verdict: weak — the "0 vs 27.3%" is true by construction, since the same table defines the truth and the whole-word judge and the segment judge is built to fail on those words. The advice (key the unhyphenated word, hyphenate only the output) is sensible, but the 27.3% number says nothing about real-world frequency.
- Hidden assumption: The segment judge in the test is a strawman: it keys only the last segment with unstressed vowels collapsed to schwa, which guarantees mo-tion, na-tion and o-cean merge. The 27.3% is a product of that design plus the 9-word list, not a measurement of how real pipelines behave. The rule also assumes the stress index and the (vowel, coda) pairs were keyed correctly by hand, so the whole-word "0 wrong" only shows the code agrees with its own truth partition.
- Would prove it wrong: The whole-word judge gets a nonzero error count once it runs against independent truth, such as a pronunciation dictionary like CMUdict, or a hand-checked rhyme list that isn't derived from the same keyed pairs. The same goes for a segment judge that is slightly smarter (it keeps the stressed segment, or the last two segments) and still scores about 27%, which would mean the problem is naive truncation, not hyphenation.
- Break scenario: Run the same exhaustive stanza test on 30 or more words with mixed stress, including multi-hyphen words (e.g. "re-mem-ber", "hap-pi-ness"), words whose stress isn't on the penultimate segment, and near-rhymes where hyphenation changes the stressed vowel. Also feed the lettering a real hyphenated lyric with the output text hyphenated and the keying left unhyphenated, to check that the output pass doesn't reintroduce the hyphens into the judge's input.
