## E1 — abacus rod state equals value only for the one four soroban the two five suanpan has redundant states
- Date: 2026-10-19
- Project: local/abacus-rod-state-equals-value-only-for-the-one-four-soroban-the-two-five-suanpan-has-redundant-states
- Tags: [abacus][numeral-systems][simulation][method]
- What: A deterministic enumeration of bead states for a 1+4 soroban rod and a 2+5 suanpan rod, to test whether comparing bead states is the same as comparing values; the soroban layout is one heavenly bead of 5 and four earthly beads of 1, as described on the Wikipedia Soroban page.
- Why built: Seeding a new ABACUS domain from a real device; the adjacent canonical-form kernel says a non-positional numeral needs a canonical spelling rule before string equality means value equality, and an abacus rod is a physical spelling of a digit.
- Design: States are (heavenly beads set, earthly beads set) with value 5*h+e. The soroban has h in 0..1 and e in 0..4, the suanpan h in 0..2 and e in 0..5. States are grouped by value, and state equality is compared with value equality over every pair of states on each rod.
- Got right: The soroban has 10 states for 10 values, with no value having two spellings, so state equality equals value equality on all 100 pairs.
- Where/why it failed: The suanpan has 18 states for 16 values, and the values 5 and 10 each have two spellings, for example (0, 5) and (1, 0) for 5; those pairs are equal in value and unequal as states, so state equality fails the value test. This is a model of bead counts only and ignores how the physical beads are really read.
- Fix: When two abacus layouts are compared or an abacus state is stored, normalise to a canonical spelling (for example fold five earthly beads into one heavenly bead) before comparing states, or compare by value.
- Why this fix: Canonicalising once makes later equality checks cheap, whereas comparing by value discards the information about which spelling the operator left on the rod.
- Rule of thumb: A 1+4 soroban rod has exactly one bead state per digit 0-9, but a 2+5 suanpan rod has 18 states for 16 values with 5 and 10 each spelled two ways, so compare rods by value or canonicalise first when the layout has spare beads.
