## E1 — sandbox t1 only a lips tongue split fits both rhyme examples
- Date: 2026-09-30
- Project: local/sandbox-t1-only-a-lips-tongue-split-fits-both-rhyme-examples
- Tags: [songwriting][rhyme][tension][testing]
- What: Exhaustive check for tension T1 of every family-rhyme rule of the form same value on feature set S, over 13 coda consonants and 5 features (manner, voicing, place, coarse place, articulator). The only rules that make mud/truck (D/K) family and read/cheap (D/P) not family are same articulator and same manner plus same articulator, which split the plosives into lip consonants (P, B) and tongue consonants (T, D, K, G). No rule built from manner, voicing or place fits, because D/K and D/P differ in exactly the same three of those features.
- Why built: lyrical-composition E3 showed the two charts on record (manner-based and strict voicing pairs) both treat D/K and D/P alike; this widens the search to every feature combination to see whether any principled chart could satisfy the kernel's two examples, which is the evidence T1 needs to be settled.
- Design: sb/music/t1_feature_rules.py with a hand-written feature table for P B T D K G F V S Z M N NG, enumerating all 31 non-empty feature subsets and testing both cited pairs, then counting how far each fitting rule diverges from the manner chart over all 78 consonant pairs.
- Got right: D/K differs in voicing, place and coarse place; D/P differs in those same three plus articulator. The same-manner-plus-articulator rule marks 10 of 78 pairs family and disagrees with the manner chart on 14 pairs, all of them lip-versus-tongue pairs such as P/T and B/D.
- Where/why it failed: The one fitting rule is not a chart any source on record uses. It exists only because the two examples happen to differ in articulator, so adopting it would fit a rule to two data points rather than follow Pattison.
- Fix: Treat the two examples as inconsistent under every documented chart: keep the manner-based chart (T1's standing lean), label read/cheap family under it, and use a cross-manner pair such as seed/leaf (D/F) as the assonance example.
- Why this fix: Every sourced reading of the chart agrees D/K and D/P belong together, so one of the kernel's two labels must be wrong, and the manner chart keeps the mud/truck example that the kernel presents as its family case.
- Rule of thumb: When two cited examples can only be separated by a rule fitted to them (here a lips-versus-tongue split), treat one example as wrong rather than adopting the fitted rule.
- Provenance (verified/assumed): Verified first-hand by running sb/music/t1_feature_rules.py; the feature table is standard articulatory phonetics written by hand. The primary Pattison text was not reachable this session (Berklee page redirected, web archive blocked), so which chart Pattison himself uses stays unchecked.
